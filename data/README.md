# Data sources and attribution

## Adult Income

The Adult Income dataset is a public machine-learning benchmark from the **UCI Machine Learning Repository**.

- Dataset: Adult / Census Income
- Creators: Barry Becker and Ronny Kohavi
- Original data: 1994 Census database
- UCI DOI: `10.24432/C5XW20`
- Licence: **Creative Commons Attribution 4.0 International (CC BY 4.0)**
- Official page: https://archive.ics.uci.edu/dataset/2/adult

The repository's root-level `adult-income-preprocessed.csv` is the processed version used by the original FairClean experiments.

Suggested citation:

> Becker, B. & Kohavi, R. (1996). *Adult* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5XW20

## International Graduates

The International Graduates dataset was used as the second empirical dataset in the submitted research. The dissertation describes it as an employment/visa-related dataset containing demographic, educational and socioeconomic variables.

The original distribution page and licence have not yet been verified confidently enough for redistribution, so the dataset is not added to this public repository.

## Why this matters

Keeping source and licence information explicit supports reproducibility while respecting dataset ownership and attribution requirements.
